# Build plan

The submission includes a hosted classroom demonstration and a reproducible local investigator workspace. The [hosting guide](HOSTING.md) lists the public endpoint, provider settings and deployment checks. Review the local stages in this order.

1. **Environment.** Initialize private settings in a fresh checkout, build all five services and provision the first investigator. Use the existing installation identity to reopen a saved workspace.
2. **Case intake.** Exercise text, email, screenshot and PDF inputs. Check consent, queue state, extraction locations and the independent posting-risk decision.
3. **Claim investigation.** Review a traceable corpus match, inspect the evidence timeline and identify exactly what the source establishes.
4. **Case linking.** Reuse an identifier across fictional cases, inspect the matching rule and masked graph, and export a report.
5. **Verification.** Run automated checks on disposable data. Distinguish synthetic coverage, historical CSV benchmarks and independent real-world evaluation.

Use the [local runbook](LOCALHOST.md) and [feature walkthrough](FEATURE_WALKTHROUGH.md) for the commands and demonstration. The [build status](BUILD_STATUS.md) records the most recent checks and any remaining limits.
